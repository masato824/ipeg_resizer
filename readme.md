# JPEG画像圧縮ツール

JPEG画像を指定した最大ファイルサイズ以下に圧縮するPythonツールです。

このリポジトリには、ブラウザで使う **Streamlit版（`app.py`）** と、PC上のフォルダーを処理する **ローカル版（`resize.py`）** の2種類があります。

## Streamlit版（Webアプリ）

公開中のWebアプリ：

https://masato824-ipegresizer.streamlit.app/

### 主な機能

- JPEG画像（`.jpg` / `.jpeg`）を複数選択可能
- 圧縮目標サイズを 20 / 10 / 5 / 2 / 1 MB から選択
- JPEGのExif情報を保持して圧縮
- 目標サイズ以下の画像は処理せずスキップ
- 1ファイルが200MBを超える場合は処理せずスキップ
- 圧縮成功が1枚の場合はJPEGとしてダウンロード
- 圧縮成功が複数枚の場合はZIPにまとめてダウンロード

### 注意事項

- **ZIPファイルのアップロードには対応していません。**
- ZIPになるのは、複数の圧縮済みJPEGをまとめてダウンロードする場合です。
- スマートフォンでは、現在の画面上の案内どおり1枚ずつ処理する使い方を推奨しています。

### ローカルでStreamlit版を起動する

```bash
pip install -r requirements.txt
streamlit run app.py
```

## ローカル版（`resize.py`）

PC上のフォルダー内にあるJPEGを一括処理する版です。

### 主な機能

- フォルダー選択ダイアログから処理対象を選択
- 圧縮目標サイズを 20 / 10 / 5 / 2 / 1 MB から選択
- JPEGのExif情報を保持
- 圧縮対象の元画像を `original/` フォルダーへバックアップ
- 圧縮後の画像で元ファイルを置き換え
- 元ファイルのアクセス時刻・更新時刻を保持
- 壊れたJPEGや処理できない画像をスキップして警告

### 実行方法

```bash
pip install -r requirements.txt
python resize.py
```

1. JPEG画像が入ったフォルダーを選択します。
2. 圧縮後の最大サイズを選択します。
3. 対象画像が処理されます。
4. 圧縮対象となった元画像は `original/` に保存されます。

## Streamlit版とローカル版の違い

| 項目 | Streamlit版 | ローカル版 |
| --- | --- | --- |
| 入力 | JPEGをアップロード | フォルダー内のJPEG |
| 複数JPEG | 対応 | 対応 |
| ZIP入力 | 非対応 | 非対応 |
| 複数出力 | ZIPでダウンロード | 元フォルダーへ保存 |
| 元画像バックアップ | なし | `original/` に保存 |
| Exif保持 | 対応 | 対応 |
| 200MB制限 | 1ファイルごとに判定 | なし |

## 動作環境

- Python 3.8以上
- 主にWindowsで使用
- 必要なPythonパッケージは `requirements.txt` に記載

## 注意

- `.jpg` / `.jpeg` 以外は処理対象外です。
- 画像の内容や圧縮率によっては、指定サイズ以下まで圧縮できない場合があります。
- 大量の画像を処理する場合は時間がかかることがあります。
- 大切な写真を扱う場合は、処理前に別の場所にもバックアップを保管してください。
